출발 전 확인해 주세요

  • 👟편한 운동화는 필수
    목적지까지 직접 걸어야 합니다. 물 한 병과 함께, 시간과 체력에 여유가 있을 때 출발하세요.
  • 📍위치(GPS) 사용 동의
    방향·남은 거리 안내와 도착 확인에 현재 위치를 사용합니다. 앱을 쓰는 동안에만 쓰며, 허용하지 않으면 이용할 수 없습니다.
  • ⚠️안전이 먼저
    걸으면서 화면을 보지 말고 멈춰서 확인하세요. 차도·공사장·사유지·출입금지 구역에는 들어가지 마세요. 밤이나 날씨가 나쁠 때는 무리하지 마세요.
  • 🔋배터리와 데이터
    위치를 계속 쓰므로 배터리가 빨리 닳습니다. 보조배터리를 권장하며, 화면이 꺼지면 위치 추적이 멈춥니다.
  • 🤝장소 에티켓
    주민의 생활 공간일 수 있습니다. 조용히 이동하고, 영업시간과 휴무일은 장소마다 다를 수 있습니다.
위치가 안 잡히거나 ‘위치 접근이 거부되었어요’가 뜨나요? +

dobalro는 현재 위치를 쓰기 때문에, 휴대폰에서 위치 권한을 허용해야 합니다. 쓰고 계신 기기에 맞춰 확인해 주세요.

›아이폰 (Safari)
  1. 설정 → 개인정보 보호 및 보안 → 위치 서비스가 켜져 있는지 확인합니다.
  2. 같은 화면에서 Safari 웹 사이트를 눌러 앱을 사용하는 동안을 고르고, 정확한 위치를 켭니다. ‘안 함’이면 위치가 막힙니다.
  3. Safari에서 dobalro를 열고 아래 주소창의 왼쪽 아이콘(페이지 메뉴)을 눌러 아래로 내린 뒤, 웹 사이트 설정 → 위치를 허용으로 바꿉니다.
  4. 홈 화면에 추가해 둔 아이콘이 있다면 지우고 다시 추가한 뒤, 위치 팝업에서 허용을 누릅니다.
  5. 그래도 안 되면 설정 → 일반 → iPhone 전송 또는 재설정 → 재설정 → 위치 및 개인정보 보호 재설정을 한 뒤 다시 시도합니다.
›갤럭시 (Chrome · 삼성 인터넷)
  1. 상단 알림창에서 위치가 켜져 있는지 확인합니다. (설정 → 위치)
  2. 설정 → 애플리케이션 → Chrome(또는 삼성 인터넷) → 권한 → 위치에서 앱 사용 중에만 허용을 고르고 정확한 위치 사용을 켭니다.
  3. 브라우저에서 dobalro를 열고 주소창 왼쪽의 아이콘을 눌러 권한 → 위치를 허용으로 바꿉니다.
  4. 홈 화면에 설치한 앱으로 열었는데도 안 되면, 설정 → 애플리케이션에서 설치된 dobalro(또는 Chrome)의 위치 권한을 확인합니다.

실내나 지하에서는 위치가 늦게 잡힐 수 있으니 창가나 야외에서 다시 시도해 보세요. VPN이나 절전 모드가 켜져 있으면 위치가 부정확해질 수 있습니다.
